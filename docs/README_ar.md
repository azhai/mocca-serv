## نبذة

يقدّم Mocca مكتبة الوسائط عبر HTTP. وهو ملف تنفيذي واحد بلغة Go —— بلا CGO، وبلا Node، وبلا CDN.
يُنشئ `make full` واجهة API مع لوحة إدارة مدمجة، بينما يُنشئ `make api` واجهة API وحدها.

## بناءان

شيفرة مصدرية واحدة، وملفان تنفيذيان. الفرق الوحيد هو وسم البناء.

| | الكامل | API فقط |
| --- | --- | --- |
| البناء | `make full` (أو `go build ./`) | `make api` (أو `go build -tags noweb ./`) |
| الناتج | `bin/mocca` | `bin/mocca-api` |
| واجهة REST + البث | موجود | موجود (مسارات التطبيق متطابقة) |
| أمر `passwd` | موجود | موجود |
| لوحة الإدارة `/admin/` | موجودة (مدمجة) | **غير موجودة** —— لا يُترجم `web/public/` |
| نقاط إدارة (التخزين، الرفع، التحرير، الغلاف/لقطة الشاشة، الإعدادات، المستخدمون) | موجود | **غير موجود** —— المجموعة كلها غير مسجلة (HTTP 404) |

## بداية سريعة

```bash
make full
./bin/mocca          # يستمع افتراضيًا على :8000
```

1. افتح `http://localhost:8000/admin/` وسجّل الحساب الأول —— أول حساب يصبح مديرًا تلقائيًا.
2. أضف وحدة تخزين: مسار التركيب `/media`، المشغّل `local`، والجذر مجلد الوسائط لديك.
3. التشغيل: `http://localhost:8000/d/media/movie.mp4?token=<الرمز>`.

هل نسيت كلمة مرور المدير أو أُدخلت بشكل خاطئ؟ سطر الأوامر هو السبيل الوحيد للعودة، وهو موجود في **البناءين**:

```bash
./bin/mocca-api passwd -u admin            # تُقرأ كلمة المرور الجديدة من stdin
./bin/mocca-api passwd -u admin -p 'كلمة-جديدة'
```

## الإعداد

يقرأ Mocca ملف `.env` من مجلد العمل (ويمكن تحديد مسار آخر عبر `MOCCA_ENV_FILE=/path/to/xxx.env`) وكذلك
متغيّرات البيئة التي تبدأ بالبادئة `MOCCA_`. الأولوية: القيم الافتراضية < البيئة < `.env`.

| مفتاح `.env` | متغيّر البيئة | الافتراضي | المعنى |
| --- | --- | --- | --- |
| `ADDR` | `MOCCA_ADDR` | `:8000` | عنوان الاستماع |
| `DATA_DIR` | `MOCCA_DATA_DIR` | `data` | قاعدة البيانات هنا؛ أما الأغلفة وملفات الفهرس فتبقى على جانب الجهاز بجوار الوسائط |
| `JWT_SECRET` | `MOCCA_JWT_SECRET` | `mocca-dev-secret` | مفتاح توقيع الرموز —— غيّره في الإنتاج |
| `ADMIN_PASSWORD` | `MOCCA_ADMIN_PASSWORD` | `@Mocca/1` | كلمة مرور أول مدير، تُستخدم فقط عندما لا يوجد أي مدير |

## الميزات

- **وحدات التخزين** —— اربط مجلدات محلية ومشاركات SMB (Samba)؛ عدد غير محدود من نقاط التركيب.
- **بث بنطاقات البايتات** —— يدعم `GET /d/<المسار>` ترويسة `Range` والنطاقات المتعددة و`HEAD` والطلبات الشرطية، فيمكن للمشغّلات التقديم والاستئناف.
- **بيانات الوسائط الوصفية** —— العنوان والمدة والغلاف والوصف وعدة مؤلفين لكل عنصر؛ الأنواع: فيديو / صوت / صورة.
- **مُنشئ صور الغلاف** (البناء الكامل فقط) —— يُصنع الغلاف من رفع المدير أو من إطار ffmpeg عند اللحظة التي تختارها (`/api/fs/shot` لملف واحد، `/api/fs/patch` لمجلد كامل)؛ ويُصغَّر إلى PNG بمقاس 400×300 ويُحفظ **على جانب الجهاز** بجوار المكتبة في `<جذر-التخزين>/.mocca/ab/cd/<بقية-sha1>.png`.
- **لوحة الإدارة** (البناء الكامل فقط) —— مدمجة وتعمل دون اتصال: وحدات التخزين، المستخدمون، البيانات الوصفية، كلمات مرور المجلدات، ورفع دفعي بشريط تقدّم مستقل لكل ملف.
- **الحسابات والصلاحيات** —— مدير / مستخدم / ضيف؛ لا يرى المستخدم إلا `base_path` الخاص به؛ 12 صورة رمزية معدّة مسبقًا (رفع الصور غير مدعوم عن قصد).
- **كلمات مرور المجلدات** —— تُضبط مرة واحدة على المجلد الأعلى، فيتطلبها الشجرة الفرعية بأكملها (بما في ذلك البث)؛ تُخزَّن بـ bcrypt.
- **التعليقات والدانماكو والمفضلة** —— التعليقات بلا حد للطول، والدانماكو حتى 50 حرفًا مرتّبة حسب زمن التشغيل، والمفضلة بلا تكرار لكل مستخدم.
- **التشغيل** —— أمر الإنقاذ `passwd`، وملف تنفيذي ساكن واحد، وكل الإعدادات في `.env`.
