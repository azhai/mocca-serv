## О проекте

Mocca отдаёт медиатеку по HTTP. Это один бинарный файл Go —— без CGO, без Node, без CDN.
`make full` собирает API вместе со встроенной панелью администратора, `make api` — только API.

## Две сборки

Один исходный код, два бинарных файла. Разница только в теге сборки.

| | Полная | Только API |
| --- | --- | --- |
| Сборка | `make full` (или `go build ./`) | `make api` (или `go build -tags noweb ./`) |
| Результат | `bin/mocca` | `bin/mocca-api` |
| REST API + стриминг | есть | есть (маршруты для приложения идентичны) |
| Команда `passwd` | есть | есть |
| Панель `/admin/` | есть (встроена) | **нет** —— `web/public/` не компилируется |
| Административные эндпоинты (хранилище, загрузка, правка, обложка/скриншот, настройки, пользователи) | есть | **нет** —— вся группа не регистрируется (HTTP 404) |

## Быстрый старт

```bash
make full
./bin/mocca          # по умолчанию слушает :8000
```

1. Откройте `http://localhost:8000/admin/` и зарегистрируйте первую учётную запись —— она автоматически становится администратором.
2. Добавьте хранилище: точка монтирования `/media`, драйвер `local`, корень — ваш каталог с медиа.
3. Воспроизведение: `http://localhost:8000/d/media/movie.mp4?token=<ваш-токен>`.

Забыли пароль администратора (или записали его неверно)? Командная строка — единственный путь назад, она есть в **обеих** сборках:

```bash
./bin/mocca-api passwd -u admin            # новый пароль читается со stdin
./bin/mocca-api passwd -u admin -p 'новый'
```

## Настройка

Mocca читает `.env` из рабочего каталога (другое расположение — `MOCCA_ENV_FILE=/path/to/xxx.env`) и
переменные окружения с префиксом `MOCCA_`. Приоритет: встроенные значения < окружение < `.env`.

| Ключ `.env` | Переменная окружения | По умолчанию | Значение |
| --- | --- | --- | --- |
| `ADDR` | `MOCCA_ADDR` | `:8000` | Адрес прослушивания |
| `DATA_DIR` | `MOCCA_DATA_DIR` | `data` | Здесь лежит база данных; обложки и индексы — на стороне устройства, рядом с медиа |
| `JWT_SECRET` | `MOCCA_JWT_SECRET` | `mocca-dev-secret` | Ключ подписи токенов —— смените в проде |
| `ADMIN_PASSWORD` | `MOCCA_ADMIN_PASSWORD` | `@Mocca/1` | Пароль первого администратора, только если администраторов ещё нет |

## Возможности

- **Хранилища** —— локальные каталоги и SMB-ресурсы (Samba); точек монтирования сколько угодно.
- **Потоковая передача по диапазонам** —— `GET /d/<путь>` поддерживает `Range`, несколько диапазонов, `HEAD` и условные запросы, поэтому плееры умеют перематывать и докачивать.
- **Метаданные медиа** —— название, длительность, обложка, описание и несколько авторов для каждого элемента; типы: видео / аудио / изображение.
- **Генератор обложек** (только полная сборка) —— обложка берётся из загрузки администратором или из кадра ffmpeg на выбранной секунде (`/api/fs/shot` для одного файла, `/api/fs/patch` для всей папки); она масштабируется в PNG 400×300 и хранится **на стороне устройства**, рядом с медиатекой, в `<корень-хранилища>/.mocca/ab/cd/<остаток-sha1>.png`.
- **Панель администратора** (только полная сборка) —— встроена и работает офлайн: хранилища, пользователи, метаданные, пароли каталогов и пакетная загрузка с отдельным индикатором для каждого файла.
- **Учётные записи и права** —— администратор / пользователь / гость; пользователь видит только свой `base_path`; 12 предустановленных аватаров (загрузка изображений сознательно не поддерживается).
- **Пароли каталогов** —— задаётся один раз на родительском каталоге, и всё поддерево (включая стриминг) требует пароль; хранится в bcrypt.
- **Комментарии, данмаку, избранное** —— комментарии без ограничения длины, данмаку до 50 символов с сортировкой по времени воспроизведения, избранное без дублей у каждого пользователя.
- **Эксплуатация** —— команда самоспасения `passwd`, один статический бинарный файл, вся конфигурация в `.env`.
